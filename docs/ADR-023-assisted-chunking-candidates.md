# ADR-023：受约束 AI 切片候选，不隐式替换历史索引

状态：实现中，候选评估能力；全面启用仍须 CZ-N02 黄金集与产物版本验收。

AI 只返回窗口内原文块的连续分组终点，程序校验编号、顺序、完整覆盖、预算和表格
邻接关系。原文、结构块、现有切片和向量不被模型输出覆盖。PDF 错误标题在候选中
保守纠正；Excel/数据库数据集继续走目录发现与精确执行，不能改成逐行向量。

网页管理入口 POST /api/documents/{id}/chunking-preview 使用现有管理员与空间鉴权，
在服务层构建候选。每次最多两次模型调用，未覆盖窗口明确保持规则处理。响应只返回
指标、覆盖与有限样例；完整候选不写入服务索引。源结构指纹与模型身份、策略版本用于
缓存，模型调用结束后再次检查当前版本与结构指纹，防止把旧候选挂到新资料上。
比较使用当前默认切片配置，不将重算的规则基线冒充正在服务的索引数量。

首次显式点击即允许将有限窗口发送到已配置对话渠道；检索/MCP 读取不触发模型调用。
此管理端点不是 /api/v1 或 MCP 公共工具，不扩大 PAT/探索凭证写权限。

候选预览不宣称已启用 AI 切片。基于至少 30 个真实跨类型问题验证后，再实现/启用
派生产物版本、候选向量覆盖、原子激活与回滚；在此之前不增加直接替换按钮。

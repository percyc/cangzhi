# ADR-034：跨进程模型调用准入

日期：2026-10-23。实施分支：`codex/CZ-Q09-reliability-complete`。
本 ADR 取代先前草案的接线缺口；发布验收及实际部署以 PROJECT_STATUS / DEVLOG 为准。

后续冷却范围与前台预留规则由 [ADR-037](ADR-037-interactive-model-priority.md)
细化：共享额度不等于共享所有故障；401/403/5xx按模型身份隔离，429仍保守共享。
以下保留最初决策记录，新实现需要迁移0044并同步更新所有外发进程。

## 决策

- API 和 Worker 通过 PostgreSQL 短事务共用额度，不按空间、模型名称或 Profile
  复制渠道配额。默认全部共用 `model` 池：总并发 2、后台最多 1、OCR 子限额 1。
  只有确认上游额度独立时，才用非敏感的用途到池映射分开。CPU 任务仍串行。
- 接线覆盖对话、摘要分类、AI 增强/辅助切片、深度分析、查询向量、后台向量、
  canary、设置页模型测试及外部 OCR；获取模型名称列表不消费生成额度。
- 外发前获取名额，准入事务在网络请求前结束。唯一持有者令牌 CAS 释放；
  槽位 TTL 大于请求绝对总期限。协调库失联时拒绝新请求，不静默绕过限制。
- 传输使用 AsyncClient 和总期限；同步调用通过独立事件循环完成真实异步传输。
  外层 `to_thread` 取消不代表请求中断：线程内请求继续到结束或总期限，期间保留名额。
  异步取消等待传输清理；获取名额期间取消也要等待有限数据库操作完成并释放迟到租约。
- 释放失败保留租约到期，不丢弃成功响应、不诱发付费重放。进程崩溃后残余租约保守
  等待到期。客户端取消不能保证供应商立即停止计算或计费，不承诺恰好调用一次。
- Busy / Unavailable / Cooldown / 发送前 Deadline 表示未外发：后台延后且不增加
  应用重试次数；仅退回与当前增强尝试匹配的未发送调用预算，不覆盖取消或继任尝试。
  实际发送后超时不能冒充未调用；付费增强结果未知不自动重放。
- 429 采用有界 Retry-After（秒或 HTTP 日期，缺失时 60 秒）；401/403 冷却 300 秒，
  临时 5xx 冷却 60 秒。更短冷却不覆盖已有更长冷却。HTTP 层不叠加自动重试。
  不将 Ollama 兼容探测的 404 当作渠道故障，兼容回退共享同一个绝对总期限。

## 配置与边界

迁移 0042 新增 `model_admission_pools` / `model_admission_leases`。
API 与 Worker 的 Compose 均透传 `MODEL_ADMISSION_CAPACITY`、
`MODEL_ADMISSION_BACKGROUND_CAPACITY`、`MODEL_ADMISSION_MAX_OCR`、
`MODEL_ADMISSION_POOL_MAP`。用途键为 `chat`、`embedding`、`ocr`；池 ID 不能包含秘密。
默认容量只在首次创建池时写入，已存在池以数据库行中的配置为准；修改环境变量不会
覆盖既有池容量。当前没有额度管理 UI，维护者调整须协调所有调用进程并核对实际池值。
总容量为 1 时无法额外预留前台容量，不承诺请求公平调度。

并发控制不是 RPM/TPM 限流。永久渠道暂停、自动故障探测、多账号管理及动态配置页面
留作后续，不将短时冷却宣称为这些能力。未改变 REST/MCP 范围或授权契约。

## 验证与发布

核心测试覆盖真实本地 HTTP 慢响应/取消、重复取消获取、释放失败保留成功结果，
以及隔离 PostgreSQL 多进程总量、后台/OCR 子限额、CAS、锁超时、租约过期和冷却。
调用点另有 Provider/OCR/向量/设置页与增强预算回归；不以核心测试代替接线验收。

依赖迁移 0042/0043，与 ADR-035 一同发布。先备份、等待旧执行器自然结束，再迁移并
替换全部 API/Worker，避免旧调用点绕过配额。回退旧镜像前先停止新执行器；新增表可
暂留，不在在线写入时降级数据库或清空租约。运行概览展示采样占用而非实时承诺。

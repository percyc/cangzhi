# ADR-025：保留主证据的有界补充片段

状态：已实现，2026-09-19 经维护者明确授权合并部署；扩大黄金集仍待完成。关联 CZ-R01 / CZ-R02 / CZ-R04。

## 问题与取舍

文档级RRF固定返回全文首片段会遗漏同文档其他已召回证据。30道本地资料检查中，
正文特征重选代表段落从21/30提高到26/30，但引入2道退步：更相似不代表更完整。
因此不采用无条件替换主片段，也不继续堆领域关键词、放大向量数量或调用回答模型重排。

## 决定

- 保持原有文档排名、分页、主chunk、snippet、context及检索通道含义。
- 在已授权的两路候选中，每文档每路最多8条，依据全文问题特征、正文覆盖与标题降权，
  选择至多1条不同的补充锚点。无新信号不增加；数据集表格仍保持精确查询导航。
- 搜索响应新增可选 `hits[].supporting_evidence` 数组，最多1项，包含
  `document_id`、`document_version_id`、`chunk`定位、`snippet`、`context`。
  主/补充context各最多1800字符，总context每文档最多3600；不合并为伪连续原文。
- 权限条件在原召回SQL下推。补充锚点必须与主证据同文档、同版本，不新增无范围查询。
  候选行不序列化，响应不泄露Scope Key、边界或内部评分。
- MCP/REST/CLI透传同一服务结果；工具描述与Skill说明提醒外部AI同时查看补充证据。
  深度分析观察提供补充锚点并允许读取，最终引用分别保留chunk身份。快速问答现有独立
  证据召回不在本批修改。网页普通搜索可保持原预览，不要求客户端才能识别新字段。
- 不增加模型调用，不修改原文、切片、向量、默认模型配置；保留无向量降级。

## 验收与边界

主证据逐字段与基线一致；跨空间/选择/探索凭证边界、版本、预算、空查询、数据集与降级
均有回归。30道初始本地问题只做来源短语覆盖检查，不等同语义正确率或代表性黄金集；
本次部署与验收记录见 EVIDENCE_SELECTION_EVAL。候选中根本没有正确证据时，本策略无法补全。

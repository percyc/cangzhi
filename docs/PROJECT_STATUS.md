  联合备份与隔离恢复演练。

  `integrations/skills/cangzhi-knowledge/` Skill 模板。
- **F 个人多工作空间**：单管理员可创建 / 切换 / 归档工作空间；文档、分类、
  标签、知识范围、WebDAV、问答记录按空间隔离；模型、备份仍全局共享。
- **G 结构化数据库来源**：PostgreSQL/MySQL 加密连接、只读浏览、本地数据集
  快照、DuckDB 受控查询。

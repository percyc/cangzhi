# 页面验收记录

## 2026-09-14 发布前检查（CZ-Q08）

使用 Chromium、真实 Next.js 页面和独立 SQLite API，桌面视口 1440×1000、手机
视口 390×844。临时管理员与示例资料只在隔离环境创建，不使用生产凭据或修改生产资料。

共 52 个页面/状态检查通过，无接口 5xx、未捕获页面异常或全页横向溢出：

| 范围 | 检查内容 |
|---|---|
| 首页与知识库 | 首页、资料列表、示例 Markdown 详情、回收站空状态 |
| 采集 | 链接收藏、随手记新增/编辑、文件上传入口 |
| 使用知识 | 收件箱、搜索、问知识、分类、标签 |
| 设置 | 对话模型、向量索引、图片文字识别、知识源、外部接入、数据与备份、工作空间 |
| 登录与初始化 | 首次初始化表单、已有管理员时初始化入口转登录、登录表单与成功提交 |
| 旧入口 | `/processing` 转收件箱，`/sources` 转知识源设置 |

发现并修复：手机收件箱六列表格压缩严重，改为两列状态信息卡片，保留向量进度
和可检索状态；桌面仍显示表格，两者使用同一分页数据与操作逻辑。

发布验证：生产 API 镜像内运行完整 API/Worker 测试，656 项通过；Web lint、
typecheck 与生产构建通过。构建前补齐 `.dockerignore` 的 `backups/` 排除项，
避免数据库和原文件备份进入镜像。

边界：本轮是页面加载、布局和基础入口验收；未对生产数据执行新增、删除、重解析、
模型调用、远程 WebDAV 写入或收费问答。PDF/Word 的格式与解析由现有后端回归测试
覆盖，本轮浏览器详情页使用 Markdown 示例。手机采用视口模拟，不等于真实设备测试。

复现：先运行 `.venv/bin/python scripts/page-review-api.py`，再在 `apps/web` 运行
`API_URL=http://127.0.0.1:18081 npm run dev -- --hostname 127.0.0.1 --port 13101`，
然后运行 `node scripts/review-pages.cjs`。需可用 Playwright；可用
`PLAYWRIGHT_MODULE` 和 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定本机安装。
每次重跑前重启隔离 API，以创建空白数据库。截图和 JSON 报告输出到临时目录。

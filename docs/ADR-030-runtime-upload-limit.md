# ADR-030：运行时文件上传限额

状态：按维护者2026-10-17要求实施。

管理员在设置页修改全局单文件上传限额，默认50 MiB；未设置时兼容
MAX_UPLOAD_SIZE_MB。保存后对新请求立即生效，不追溯拒绝已上传资料。
浏览器上传与 REST v1 写入共用同一服务读取限额；鉴权、文件类型、幂等与返回状态码
保持不变，超过限额仍返回413。管理配置仅管理员可读写，普通PAT不能改系统配置。

Web 文件上传采用 Node 流式透传，不经过 Next 代理的固定克隆缓冲限额，避免
设置已保存却必须重新构建。普通 API 路由不变；根路径与子路径上传均需测试。
外部 Nginx/client_max_body_size 和其他网关的限制由部署者调整，界面给出提示。
不引入第二个产品级部署上限；数值必须为正整数且在数据库整数范围内。

本设置只影响主动文件上传；网页抓取、WebDAV来源下载、OCR页数、解压/表格资源
保护保持独立。大文件仍消耗临时磁盘、处理时间和存储；不是无限容量承诺。

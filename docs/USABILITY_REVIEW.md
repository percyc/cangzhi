# 全局页面易用性审查（2026-09-29）

本轮由 `codex/CZ-UX-global-usability` 承接 CZ-U05 / CZ-UX。目标是让用户在页面内理解
“当前在哪、能做什么、操作会影响什么、下一步去哪”，而不是增加另一套功能入口。
应用事实源、服务层、检索、模型策略、权限与数据库 Schema 不变。

后续发布：维护者明确要求“合并后部署并推送”，`f1f7758` 已快进合并main并部署至
既有3000端口，仅更新Web。以下预览记录保留为首轮审查过程；实际发布验收另见DEVLOG。

## 审查范围

已盘点全部23个 `page.tsx`，包含动态详情和随手记编辑页；模型设置另检查对话、向量、
OCR三个面板。检查导航与默认路径、加载/空/错误状态、保存与批量操作、可选能力说明，
并检查来源管理、在线切片、候选评估和引用预览组件的操作边界。

| 页面组 | 入口 | 本轮处理 |
| --- | --- | --- |
| 首次使用与登录 | `/setup`、`/login`、`/` | 首次建号后到真实知识库，不强制先配置模型；不改认证 API |
| 资料浏览 | `/documents`、`/categories`、`/tags` | 直接上传/笔记/链接入口；分类为空与全库为空分开；读取失败有重试；表单与筛选补可访问名称 |
| 入库检查 | `/inbox`、`/processing` | 提示待整理不等于不能检索、批量仅当前页；保留统一阶段与队列口径 |
| 录入与编辑 | `/files/upload`、`/notes/new`、`/notes/[id]/edit`、`/links/new` | 上传与后续处理分开说明；新笔记网络失败解除保存状态并保留输入；阻止重复提交、空白笔记；链接错误对象不直接渲染 |
| 内容核验 | `/documents/[id]` | 就地说明原文/解析/在线切片/候选区别；不重切、不调用模型生成候选 |
| 搜索与问答 | `/search`、`/ask` | 说明找原文与归纳的区别；手机保留工作空间和主导航；模式/范围提示、输入可访问名称与快捷键说明 |
| 模型与检索 | `/settings` 的3个面板、`/settings/enhancement` | 三组设置导航；可选能力与计费边界；保留连接→可选获取模型→手输/选择→保存测试流程 |
| 来源管理 | `/settings/sources`、`/sources` | WebDAV与数据库都出现在导航说明；区分连接、导入、快照和刷新；不改来源、不触发导入 |
| 工作空间 | `/settings/workspaces` | 默认先看已有空间；新建与长说明就地折叠；中文名称自动产生合法标识，仍可手动改写 |
| 维护与接入 | `/settings/data`、`/settings/access`、`/settings/account` | 统一导航与操作提示；纠正“备份校验尚未交付”的旧文案，明确服务器工具可用但网页不执行恢复 |

## 设计取舍

![独立预览中的设置分组与数据备份页面，已裁去账户顶栏](images/usability-settings.jpg)

- 桌面设置使用分区侧栏：模型与检索、资料与连接、系统与安全。说明不再挤在九列中。
  手机和平板使用带分组的原生选择器；原有未保存模型设置的离开确认仍生效。
- 使用提示默认折叠，在页面内展开，不弹出大向导或阻断工作流。提供三步操作、一个重要
  边界和相关下一步。问答说明放在自己的欢迎区，避免挤压固定高度的输入区。
- 工作空间用于确有隔离需求的项目；普通整理优先分类与标签，不引入新的空间层级或团队权限。
- 新建笔记失败不丢掉当前输入，但不宣称已有自动草稿。中文空间名的自动标识只在新建时
  生成，不改现有标识、API契约或资料所属空间；后端仍做唯一性和格式校验。

## 验证与安全范围

- `npm run test:ux`：13项，覆盖全部页面帮助映射、设置分组、导航归属、分类空状态、
  中文标识、错误对象、空白/忙碌提交、网络及HTTP失败、成功跳转与设置切换确认保护。
  表单测试使用无网络的模块/Hook替身，不向生产 API 提交内容。
- Web ESLint、TypeScript、Next.js生产构建与 `git diff --check`。
- Chrome只读检查全部页面组；390×844手机20个业务页面、768×1024平板15个页面均未发现
  根页面横向溢出。复核模型表单、合成文档与编辑页的加载完成状态，不将加载占位算作验收。
- 实际点击验证分类空状态/返回全部、手机设置分类切换和就地帮助展开；浏览器不执行
  改密、权限/令牌操作、删除、模型测试、索引构建、导入、重处理或问答生成。
- 新建空间表单已实际填写中文名称，确认自动标识符合格式；仅检查草稿，没有提交创建。
- 开发模式的资源来源限制影响首次预览，最终验收改用独立生产构建预览；它复用现有API，
  使用“产品演示”空间做只读检查。没有替换运行在3000端口的服务或执行Compose部署。
  本轮未新增正式资料、未改变模型配置；临时视口已恢复。

## 2026-10-04 状态可靠性续批（CZ-U07）

本批从同步后的 `e374f73` 开发，分支为 `codex/CZ-U07-state-reliability`。优先修复会影响
资料保全、结果归属与恢复动作的问题，不把布局调整代替正确性修复。

- 文档处理轮询保留编辑草稿、分类选择及阅读页签；服务器版本/组织信息变化时提示核对。
  慢轮询不重叠，迟到结果不能覆盖刚保存的内容。此处是页内保护，不是跨页自动草稿。
- 数据预览绑定数据集、文档/产物版本和分页；切换失败不再显示上一张表的行，提供当前页
  重试。刷新错误明确提示当前仍为保留快照，而非源库最新状态。
- 问答的新建、历史切换、取消和卸载隔离旧请求的答案、进度与错误；发送期间新输入不被
  旧结果清空。网络异常不自动删除服务端会话，避免丢失已经保存的答案。取消页面请求不承诺
  已取消服务端模型计算；是否已保存结果可从历史记录核对。
- 问答偏好按工作空间保存，并校验范围、分类、标签和连接器；失效筛选清除并提示。旧的
  跨空间共用偏好键不自动迁移，避免把无法确认所属空间的过滤条件带入新空间。
- 搜索新增分页、完整 URL 筛选状态和主命中片段定位；纯筛选模式正确使用 offset/limit。
  关键词/混合检索仍使用原有有界候选，不承诺遍历全部资料，不修改排名或引入模型调用。
- 收件箱区分未启用向量与索引异常，数据库刷新失败可进入来源异常；重试只恢复失败阶段，
  批量汇报提交、无需操作与失败数量。待治理表格仍留在待整理，同源正常表不因单表刷新
  失败被标记异常。完整重新处理单独确认；旧的完整重处理失败任务不通过普通重试绕过确认。
- 数据库空表刷新不再删除旧资料和历史，而是保留证据、记录错误并标记过期；首次空表仍跳过。

验证采用合成资料、内存数据库和实际页面/处理函数的受控异步测试；具体数量和运行结果见
本批 DEVLOG（API123项、Worker刷新3项、Web45项）。未对运行实例执行导入、重试、删除、模型调用或部署，也不把模拟交互当作
真实浏览器或全库知识质量验收。

下一批仍需完成：按空间隔离的跨页草稿与离页保护；桌面“资料列表—原文/数据—问答证据”
可收缩分区及移动端等价导航；真实登录态、软键盘和完整无障碍验收。上述布局尚未在本批交付。

## 2026-10-04 原生阅读工作台与跨页草稿（CZ-U08）

本节接续上述“下一批”事项，不覆盖整个长期 BACKLOG，也不改变事实源、数据集精确查询
或公共接口的产品边界。操作说明和验收命令见 [阅读工作台](WEB_WORKBENCH.md)。

- 搜索改为原生结果/阅读双区，桌面并排、手机切换；关闭阅读保留条件、分页与列表位置，
  返回触发控件。预览注明命中上下文、文档/数据版本，失败可就地重试，不显示旧请求残留。
- 问答改为范围与记录/对话/引用证据三区；桌面可收起两侧，手机直接换区。
  证据阅读不阻塞提问，不锁定整个页面；侧区收起不卸载已经选定的证据内容。
- “仅问这份资料”传递显式文档限制，不自动发送；问题草稿按空间与文档范围隔离。
  每次问答仍独立检索，不误导为模型记住历史。
- 随手记使用按空间和资料编号隔离的标签页草稿，24 小时/512 KiB；恢复和丢弃可见，
  超限、不可用或过期不冒充已暂存。编辑前读失败不能保存空表，版本变化先核对。
- 共享离页保护覆盖资料整理、网页录入、待上传文件、模型设置与未能暂存的草稿；
  登录过期给出返回原页入口，不自动丢弃编辑页。敏感配置和文件二进制不进入草稿存储。
- 真实浏览器暴露并修复了两个仅靠单元模拟未发现的问题：捕获/冒泡之间的 microtask
  造成重复确认；旧搜索页在后退卸载前的 URL effect 将目标地址抢回。分别以整次事件的
  有界确认许可、Next history 安装顺序/索引保留及路由归属校验修正。
- 模型保存期间锁定表单，避免成功回调清空之后新输入的密钥；登录入口点击时解析最新
  query/hash，避免回到同一页面的旧筛选状态。

验收记录以本轮 DEVLOG 最终条目为准。运行实例、真实模型、外部来源写入及部署均未操作。
仍然明确保留的边界：标签页草稿不是云端/跨设备保存；编辑版本检查不是服务端原子 CAS；
手机压缩视口不等于真机输入法/屏幕阅读器验收；完整文档管理与搜索、问答仍是相连的
独立路由，而不是一个无限叠加面板的页面。既有依赖安全告警另列 CZ-SEC01。

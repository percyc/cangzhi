# 全局页面易用性审查（2026-09-29）

本轮由 `codex/CZ-UX-global-usability` 承接 CZ-U05 / CZ-UX。目标是让用户在页面内理解
“当前在哪、能做什么、操作会影响什么、下一步去哪”，而不是增加另一套功能入口。
应用事实源、服务层、检索、模型策略、权限与数据库 Schema 不变。

## 审查范围

已盘点全部23个 `page.tsx`，包含动态详情和随手记编辑页；模型设置另检查对话、向量、
OCR三个面板。检查导航与默认路径、加载/空/错误状态、保存与批量操作、可选能力说明，
并检查来源管理、在线切片、候选评估和引用预览组件的操作边界。

| 页面组 | 入口 | 本轮处理 |
| --- | --- | --- |
| 首次使用与登录 | `/setup`、`/login`、`/` | 首次建号后到真实知识库，不强制先配置模型；不改认证 API |
| 资料浏览 | `/documents`、`/categories`、`/tags` | 直接上传/笔记/链接入口；分类为空与全库为空分开；读取失败有重试；表单与筛选补可访问名称 |
| 入库检查 | `/inbox`、`/processing` | 提示待整理不等于不能检索、批量仅当前页；保留统一阶段与队列口径 |
| 录入与编辑 | `/files/upload`、`/notes/new`、`/notes/[id]/edit`、`/links/new` | 上传与后续处理分开说明；新笔记网络失败解除保存状态并保留输入；阻止重复提交、空白笔记；链接错误对象不直接渲染 |
| 内容核验 | `/documents/[id]` | 就地说明原文/解析/在线切片/候选区别；不重切、不调用模型生成候选 |
| 搜索与问答 | `/search`、`/ask` | 说明找原文与归纳的区别；手机保留工作空间和主导航；模式/范围提示、输入可访问名称与快捷键说明 |
| 模型与检索 | `/settings` 的3个面板、`/settings/enhancement` | 三组设置导航；可选能力与计费边界；保留连接→可选获取模型→手输/选择→保存测试流程 |
| 来源管理 | `/settings/sources`、`/sources` | WebDAV与数据库都出现在导航说明；区分连接、导入、快照和刷新；不改来源、不触发导入 |
| 工作空间 | `/settings/workspaces` | 默认先看已有空间；新建与长说明就地折叠；中文名称自动产生合法标识，仍可手动改写 |
| 维护与接入 | `/settings/data`、`/settings/access`、`/settings/account` | 统一导航与操作提示；纠正“备份校验尚未交付”的旧文案，明确服务器工具可用但网页不执行恢复 |

## 设计取舍

![独立预览中的设置分组与数据备份页面，已裁去账户顶栏](images/usability-settings.jpg)

- 桌面设置使用分区侧栏：模型与检索、资料与连接、系统与安全。说明不再挤在九列中。
  手机和平板使用带分组的原生选择器；原有未保存模型设置的离开确认仍生效。
- 使用提示默认折叠，在页面内展开，不弹出大向导或阻断工作流。提供三步操作、一个重要
  边界和相关下一步。问答说明放在自己的欢迎区，避免挤压固定高度的输入区。
- 工作空间用于确有隔离需求的项目；普通整理优先分类与标签，不引入新的空间层级或团队权限。
- 新建笔记失败不丢掉当前输入，但不宣称已有自动草稿。中文空间名的自动标识只在新建时
  生成，不改现有标识、API契约或资料所属空间；后端仍做唯一性和格式校验。

## 验证与安全范围

- `npm run test:ux`：13项，覆盖全部页面帮助映射、设置分组、导航归属、分类空状态、
  中文标识、错误对象、空白/忙碌提交、网络及HTTP失败、成功跳转与设置切换确认保护。
  表单测试使用无网络的模块/Hook替身，不向生产 API 提交内容。
- Web ESLint、TypeScript、Next.js生产构建与 `git diff --check`。
- Chrome只读检查全部页面组；390×844手机20个业务页面、768×1024平板15个页面均未发现
  根页面横向溢出。复核模型表单、合成文档与编辑页的加载完成状态，不将加载占位算作验收。
- 实际点击验证分类空状态/返回全部、手机设置分类切换和就地帮助展开；浏览器不执行
  改密、权限/令牌操作、删除、模型测试、索引构建、导入、重处理或问答生成。
- 新建空间表单已实际填写中文名称，确认自动标识符合格式；仅检查草稿，没有提交创建。
- 开发模式的资源来源限制影响首次预览，最终验收改用独立生产构建预览；它复用现有API，
  使用“产品演示”空间做只读检查。没有替换运行在3000端口的服务或执行Compose部署。
  本轮未新增正式资料、未改变模型配置；临时视口已恢复。

## 仍需完善，不能算作已完成

1. **草稿与未保存离开保护**：笔记目前仅在失败后保留页内输入，没有跨页/跨设备草稿；
   后续应设计不保存密钥、按空间隔离的草稿恢复，并补路由离开保护测试。
2. **键盘与无障碍**：本轮补导航归属、字段名称与焦点描边；所有弹层焦点陷阱、全部页签
   方向键语义与屏幕阅读器验收还没有完成。
3. **来源操作的完整端到端场景**：本轮不连接真实外部库做导入/取消/刷新；后续应使用
   合成数据库验证已有表、空快照、失败、重试、版本与预算反馈，而不是只检查空列表。
4. **文档阅读质量**：不同类型的长文、PDF版式、Markdown原始格式与解析格式对照、
   数据集字段与证据行仍需独立回归，不能用一条演示笔记证明解析和问答质量。
5. **错误状态统一**：关键录入错误已修；旧页面仍有独立请求处理与原生重命名提示框，
   应逐步收敛，而不是本轮整体替换所有领域组件。
6. **有屏幕键盘的手机**：固定输入区已按主导航高度调整；仍需真实iOS/Android软键盘、
   旋转、长回答和慢网络交互验收。布局无溢出不等于所有触控与中断路径都已通过。

下一批优先补草稿保护和受控失败/中断测试，再完善来源管理与引用阅读；不以继续新增入口
为目标。本轮纯Web改动，无后端迁移，不改变已发布 `v1.3` 标签。

# ADR-036：引导配置、连接复用与设置搜索

日期：2026-10-23。任务 CZ-U10。

## 决策

- 在设置入口提供原生分步配置，按“对话与整理 → 可选语义检索 → 可选外部OCR →
  使用入口”组织。已有详细设置仍保留，所有模型配置全局共享。不开AI也能保存资料。
- 复用现有表单、保存、连接测试和索引生命周期，不另建一套配置源。保存不等于测试
  通过，测试通过不等于向量索引生效；测试和索引构建的费用/历史补跑影响必须提示。
  向量单独保存不得触发对话的未整理补跑。候选连接与活动Profile不匹配时现有检索
  会降级关键词，不能仅因旧索引存在就宣称语义检索不中断。
- 允许显式选择已保存的OpenAI兼容对话连接作为向量/OCR的配置来源；服务端复制
  地址及加密密钥，模型名称独立选择。此操作是一次性复制而非持续绑定，后续更换
  对话连接不静默更改向量或OCR。向量模型与视觉模型不能根据列表名称保证可用。
- 密钥不回显、不放入浏览器持久存储、不提交给辅助AI。未保存草稿不作为其他渠道
  的已保存连接；用户可随时选择独立地址与密钥。
- 设置/功能搜索采用本地静态目录与中文常用问法，结果跳到真实入口，不搜索用户资料
  或配置值，不调用模型。配置页需保留未保存修改的离开确认，手机和键盘均可使用。
- 本批不增加自由AI对话配置：未配置模型时需要帮助，依赖模型会形成循环；配置规模
  尚可由目录、问法搜索与引导覆盖。将来若增加，只能生成可核验的建议与配置差异，
  不接收密钥，不自动保存、测试、构建或删除。

## 边界

本批不增加供应商账户管理、持续连接引用或动态额度UI；不改变REST v1/MCP、上传、
Scope Key契约。无需数据库迁移。现有模型额度和安全边界保持不变。

# 藏知产品范围

## 1. 产品目标

藏知不是一个“上传文件后聊天”的工具，而是一个自动整理的个人知识中枢。用户只负责把内容交给系统；系统负责保存、理解、归类、建立索引，并在需要时准确找回。

首版的北极星指标：

> 用户保存资料后不进行额外整理，数周后仍能通过搜索或自然语言提问准确找到，并能核对原文出处。

## 2. 首要用户

第一阶段只服务单个用户，不引入团队空间、复杂权限和审批流程。主要资料包括：

- 读到的优质网页文章
- PDF、Word、Markdown、TXT、扫描图片
- 工作研究资料
- 灵感、观点和临时笔记
- 少量法律、政策和合同类资料

## 3. 核心用户流程

### 3.1 链接入库

1. 用户粘贴 URL。
2. 系统立即创建一条“处理中”的资料记录。
3. 后台下载网页，保存原始 HTML 和正文快照。
4. 系统提取标题、作者、发布日期、来源和正文。
5. AI 识别主题、摘要、分类、标签和实体。
6. 系统完成结构化切片及全文/向量索引。
7. 高置信度资料自动归档；低置信度资料进入“待整理”。

### 3.2 文件入库

1. 用户拖拽或选择文件。
2. 系统计算哈希，提示重复文件但不静默覆盖。
3. 保存原文件并创建版本记录。
4. 根据文件格式执行文本、版面、表格或 OCR 解析。
5. 后续步骤与链接入库一致。

### 3.3 随手记

1. 用户输入一段文字，可选填写标题。
2. 系统即时保存，不等待 AI。
3. 后台补充标题、摘要、分类、标签和关联资料。
4. 用户可以把多条笔记合并成专题，但首版不自动改写原始笔记。

### 3.4 搜索与问答

1. 用户输入关键词或自然语言问题。
2. 系统判断是“找资料”还是“基于资料回答”。
3. 并行执行全文、向量和元数据检索。
4. 融合并重排候选结果。
5. 搜索模式返回文档和命中片段；问答模式生成带引用的回答。
6. 每条引用可打开到原文对应章节、页码或段落。

### 3.5 用户纠正

- 移动主分类
- 增删标签
- 修改摘要
- 合并或拆分片段
- 标记错误解析或错误引用

每次纠正记录修改前后值、时间、对象和原因。首版先用于审计和规则示例，后续再用于自动学习。

## 4. 信息架构

### 4.1 一级入口

- 收件箱：处理中、失败和待整理资料
- 知识库：按主分类浏览所有资料
- 搜索：统一搜索与问答
- 专题：保存的查询和智能集合
- 随手记：快速记录入口
- 设置：模型、存储、解析模板和导出

### 4.2 默认主分类

- 工作与项目
- 行业与商业
- 技术与产品
- 法律与政策
- 财务与投资
- 人文与社会
- 个人成长
- 生活与健康
- 灵感与随手记
- 待整理

主分类为单选树；标签、实体和专题允许多选。用户可以增删分类，但删除前必须迁移或解除其中资料。

## 5. AI 自动化策略

### 5.1 默认自动完成

- 文档类型识别
- 标题清理
- 简短摘要
- 主分类推荐
- 标签生成
- 关键实体提取
- 解析模板选择
- 重复内容提示

### 5.2 置信度行为

- `>= 0.85`：自动归类。
- `0.60～0.85`：自动归类，在收件箱保留轻量提示。
- `< 0.60`：归入“待整理”。

阈值是首版默认值，后续通过真实使用数据校准，不把大模型自报置信度当作唯一依据；还需要参考分类相似度、规则命中和历史一致性。

### 5.3 低打扰原则

- 入库过程不要求逐项确认。
- 多个低置信度项目集中处理，不连续弹窗。
- 高级提示词不出现在日常主流程。
- AI 失败不阻止原文保存，允许稍后重试。

## 6. 第一版范围

### 必须完成

- URL、文件、随手记三种采集方式
- 原文和版本保存
- PDF、DOCX、Markdown、TXT、HTML 基础解析
- 图片或扫描 PDF 的 OCR 兜底
- 自动摘要、分类和标签
- 结构优先切片
- 全文 + 向量混合检索
- 带原文引用的问答
- 分类/标签/片段的基本修改
- 处理状态、错误原因与手动重试
- 模型 Provider 配置
- 数据导出与基础备份说明

### 暂缓

- 多用户和组织权限
- 邮件自动收件
- 浏览器插件和移动原生 App
- 全量知识图谱
- Agent 主动联网研究
- 复杂协同批注
- 训练或微调专属模型
- 自动删除、自动覆盖和不可逆内容重写

## 7. 个人 Beta 增量

- 专用入库邮箱或 IMAP 邮箱轮询
- 浏览器一键收藏
- 法律/合同解析模板
- 相似资料、重复观点和冲突提示
- 保存查询形成动态专题
- Markdown/JSON 全量导出
- 定时备份与恢复演练

## 8. 验收指标

- 新建资料记录在 1 秒内可见，后台处理不阻塞界面。
- 常见网页和文本型 PDF 的正文解析成功率达到 90% 以上。
- 20 个真实测试问题中，正确支持片段进入前 5 名的比例达到 80% 以上。
- 生成回答中的事实引用覆盖率达到 90% 以上。
- 点击引用能够定位原文，不只跳到文档首页。
- 日常入库中需要人工重新分类的比例低于 20%。
- 任一 AI 步骤失败时，原文件和基础元数据仍然可用。

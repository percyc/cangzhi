# 文档理解与自主探索演进

状态：方案方向已获维护者认可，分批实现。起点为 `v1.0`（`8cccfb9`）。
本文是计划，不代表以下能力全部可用。当前实现仍以 ARCHITECTURE.md 为准。

## 目标与不变量

把文档从单一切片集合升级为可导航、可查询、可核验的知识：原文件与版本为事实源；
解析结构、AI 理解、切片和向量为独立、可重建的派生结果。外部 AI 通过统一服务
自主探索，不因调用读取工具而隐式触发藏知大模型二次推理。

## 分批交付

1. **结构可靠性（CZ-Q06）**：Word 段落、表格按原序输出，保持标题归属和位置；
   覆盖交错正文、连续表格、空段落、异常样式和解析到父子切片的回归。
   本批不改变切片算法、公开 API、数据库结构或历史任务。
   已于 2026-09-15 合并部署；含跳级标题修复，完整 API/Worker 680 项回归通过。
2. **文档地图（CZ-N01）**：版本内结构块身份、章节树、表格对象与来源锚点；
   保留合并单元格、表头、注释与不确定性。不用模型摘要替代原文。
3. **产物版本与评测（CZ-N02）**：解析/理解/切片配置形成候选产物版本；
   完成校验后原子切换，旧证据仍可定位。至少 30 个跨类型黄金问题对照现有基线。
4. **分层 AI 理解（CZ-N03）**：文档概览、章节理解、局部上下文与依赖关系；
   大文档逐章节覆盖，显式记录完成、失败与降级范围。按内容哈希缓存、限制并发、
   调用量和预算，不为每个片段重复提交整篇文档。
5. **AI 辅助切片（CZ-N04）**：模型只提议原文块 ID / 位置范围、合并拆分边界
   与关联关系；程序校验引用存在、顺序、覆盖、重复和长度，违规自动退回结构切片。
   召回片段与阅读上下文分离，AI 说明与原文分字段索引、返回和引用。
6. **统一探索（CZ-N05）**：文档概览/目录、章节分页、块读取与上下文扩展、表格
   Schema/明细和原文定位，通过服务层供网页、REST、MCP、CLI、Skill 共用。
   实现前单独写 ADR 明确接口、分页/预算、版本身份与探索凭证交集约束。
7. **纠正与渐进迁移（CZ-N06）**：结构纠正、提示词策略、候选差异、回滚与覆盖
   状态可视化；先选少量真实资料验收，经维护者确认再重建历史资料。

## 表格路由

- 条款/条件对照表：保留阅读型表格，并关联正文解释与注释。
- 可靠二维记录：仍属于原文，同步建立数据集，复用 Parquet/DuckDB 精确查询。
- 表单、复杂合并表头与交叉矩阵：保留结构，未确认计算语义前不开放精确聚合。
- 扫描表格：识别质量不足时明确标记，不以代表行或猜测结构冒充完整数据。

不得把大表退化为每行一个向量；不得仅按文件扩展名决定是否为数据集。

## 当前推进：结构风险优先的辅助切片

保留已发布 v1，新增独立 adaptive-v2。先复用解析后的结构块，按结构风险选择模型
窗口；PDF、Word、Markdown、网页与普通文本共享同一评估。没有风险或没有有效建议
时保留完整规则基线，不把“模型未使用”伪装成 AI 分组。

第一批交付候选服务、诊断和显式维护入口开关，以及跨格式完整性回归。
随后仍需完成章节渐进处理、跨页关联、块内长文边界建议和真实黄金集；本批不宣称
全文分层理解已交付。结构化数据集原通路保持，Word 表格自动转数据集另行实现。

### 历史 PDF 如何迁移

- 正文和结构可用：复用已有版本，只评估候选；通过后定向重建切片和需要更新的向量。
- 缺少原文、OCR 缺字或阅读顺序错误：先确认问题，再针对文档重解析。
- 只有旧策略标记：不代表解析失败，不自动触发重新下载或 OCR。
- 已完成的 v1 维护任务继续保留；新 v2 不通过修改旧任务来自动覆盖历史资料。

因此不需要、也不默认执行全库 PDF 重解析。激活前仍遵守备份、小批对照、明确清单
和可恢复操作要求，新上传优先于维护任务。

## 验收与准入

评测正文覆盖、表格结构保真、证据召回完整度、引用定位成功率、探索成功率及成本。
分别比较规则基线与增强候选，覆盖制度、报告、合同、长列表、跨页表格与异常文件。
AI 输出中的文档内容一律视作不可信数据，不执行文档中的指令或模型生成代码。
数据范围在所有目录、关联边、块、表格与历史证据读取上强制校验，不能只保护搜索。
现有 ADR-004 的确定性底座保留；AI 增强启用须经过版本化、降级和评测验收。

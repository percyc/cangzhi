# 藏知当前任务清单

更新时间：2026-07-31

本文件只维护尚未完成或需要持续验证的工作。已交付能力统一记录在
[路线图的已交付基线](ROADMAP.md#1-已交付基线)，不再把历史开发日志混入当前任务。

优先级含义：

- `P0`：个人 Beta 的可靠性或质量阻塞项
- `P1`：个人 Beta 的重要体验
- `P2`：后续增强

## P0：处理状态与可观察性

| ID | 任务 | 完成定义 |
|---|---|---|
| CZ-Q01 | 统一文档处理阶段 | 列表和详情分别显示采集、解析、理解、切片、全文和向量状态 |
| CZ-Q02 | 向量覆盖诊断 | 可筛出当前 active profile 缺失或失败的文档，并批量补建 |
| CZ-Q03 | 任务统计 | 可查看各阶段耗时、失败类型、重试次数和积压数量 |
| CZ-Q04 | 大文档回归集 | PDF、Word、Markdown、代码、表格和异常编码均有可重复测试样本 |

## 完成规则

- 代码、迁移、测试、用户可见状态和文档必须一起交付。
- 任何新来源都必须验证新增、更新、删除、恢复和永久排除。
- 任何检索优化都必须经过黄金集比较，不能只凭单个示例判断。
- 任何不可逆操作必须经过影响预览和明确确认。

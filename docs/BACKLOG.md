# 藏知首版任务清单

## 使用方式

- 优先级：`P0` 阻塞首版，`P1` 个人 Beta 必须，`P2` 后续增强。
- 状态建议：`Todo`、`Doing`、`Blocked`、`Done`。
- 每个任务完成时应同时提交测试或明确说明无法自动化测试的原因。

| ID | 优先级 | 任务 | 完成定义 |
|---|---:|---|---|
| CZ-001 | P0 | 初始化 monorepo | Web、API、Worker 目录和统一命令可用 |
| CZ-002 | P0 | Compose 开发环境 | PostgreSQL/pgvector 健康检查通过 |

# ADR-032：后台 WebDAV 扫描

扫描与下载入库保持独立。管理页面通过 scan-jobs 提交持久任务，立即返回202；
旧scan接口保留兼容，不扩展公开v1/MCP契约。一个来源最多一个当前扫描任务。
Worker独立扫描循环每批最多3目录，并复用HTTP连接，不阻塞文档解析循环。

任务记录待扫目录、已发现目录、暂存文件、完成数、错误与租约；网络期间不持有
数据库锁，返回后复核任务令牌和来源配置。取消使迟到结果失效；崩溃后租约到期
重领未提交批次。失败/取消可显式继续或重新开始，完成的目录不重复扫描。

已入库清单只在完整成功后原子更新。人工继续或租约恢复的跨时段扫描只发现/更新文件，
不确认远端缺失；需要一次重新开始且完整成功的扫描才可确认缺失，避免旧目录快照误回收。
配置变化后旧任务不可继续，必须重新开始。没有真实百分比，展示实际目录/文件计数。

沿用2000目录/10万条目/单目录16MiB保护，移除整树45秒限制；每批网络30秒，
租约120秒。单次暂存仅保留当前任务，重新扫描删除旧暂存，不删除原文件或入库资料。
定时扫描、自动重试退避和无限规模导入不在本批；暂停过久建议重新开始。

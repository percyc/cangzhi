# ADR-024：可选 AI 知识增强

日期：2026-09-18。状态：方案已由维护者确认，分阶段实施，尚未交付完整功能。

## 不变的基础能力

现有正文提取、配置的 OCR、规则切片、向量/全文检索，以及 AI 摘要、分类、标签
仍是基础流程。关闭知识增强不得关闭上述 AI 整理，也不得删除已有增强产物。

## 决定

- 工作空间独立配置，默认关闭。开启须明确确认额外模型调用及内容外发；生效时间
  之后的新版本才自动处理，历史资料需显式选择批次。
- 文档地图来自结构化原文，不需要模型。按章节/受限窗口增量理解，分别记录已处理、
  失败、预算未覆盖部分；不得用局部采样标记全文理解完成。
- 模块包括章节理解、实体关系/事件、辅助切片。小说人物只是通用实体的一种，
  不以姓名相同自动认定同一实体，不为某个问题定制领域关键词。
- 每个产物绑定工作空间、文档版本、原文指纹、配置/提示词版本与生成状态。
  模型描述属于解释，必须附原文块证据；有证据锚点不等于语义已验证。
- 章节理解和图谱是补充产物。切片是替代产物：保留基线和候选，当前版本同一时间
  只有一套检索切片生效；候选向量构建完成并通过校验后才允许原子启用，支持回滚。
  旧引用可读取已发布历史产物，但不能绕过工作空间/探索凭证范围。
- 所有模块共享每文档调用预算；重试也计入预算，预算不是 token 账单。设置保存、
  普通读取、REST/MCP/CLI/Skill 探索本身不得隐式调用模型。
- 关闭开关停止未来自动增强，不自动删除、重切或切换当前索引；运行中的任务
  提供明确取消入口。增强失败保留基础服务。

## 接口边界

管理员写入使用独立增强服务；公共只读探索使用 knowledge:read，沿用工作空间、
document_selection 和 exploration_boundary。分页读取地图、章节、实体、关系、事件，
响应携带产物版本、覆盖情况和证据定位。具体 DTO 随实现补充，不提前宣称可用。

## 第二批实现契约（2026-09-18）

新增管理员空间内接口（并非 PAT 写接口）：GET/PUT `/api/enhancement/settings`；
GET/POST `/api/documents/{id}/enhancements`；GET `/api/enhancements/{run_id}`；
POST `/api/enhancements/{run_id}/cancel`、`/resume`。管理员鉴权与空间过滤强制执行。
设置含 enabled、modules（本批仅 chapter/graph）、call_budget（1–32）、cost_acknowledged；
生效时间服务端生成，设置更新不得追溯自动处理历史资料。原有通用 settings 修改不得
绕过该入口修改 enhancement 配置。基础 understanding 阶段不依赖这些设置。

运行绑定不可变结构快照及指纹，独立存储每窗口的状态、证据、模型身份与解释结果。
一项后台任务只尝试一个窗口，先持久化调用计数再请求模型，不跨模型调用持有事务；
校验失败也消费次数。结果提交前检查当前文档版本与结构是否仍一致；过期、回收或
空间归档不得继续发布。取消不删除已完成窗口，停止排队后续任务。模型失败不重试
基础解析；人工继续可追加 1–32 次，总计最多 256 次，必须重新确认费用。崩溃中窗口
通过有期限的执行租约与人工继续恢复，迟到响应以尝试 ID 拒绝，不能覆盖新结果。

默认只自动处理开关启用后的新版本；历史增强只能通过显式开始请求提交。优先维护
执行器可消费截止时间之后显式新建的 enhancement 任务，但不能因此领取旧解析。
本批仅补充知识，不启用辅助切片模块、不修改向量索引；UI 明确标注未开放能力。
GET 只读取产物并分页返回，绝不生成模型调用。外部 REST/MCP 探索接口后续独立接入，
必须复用相同文档范围过滤，未接入前不把这些管理员接口宣传成外部只读契约。

## 交付门槛

开关/预算单测、版本生命周期与并发启用、原文不变、旧引用、范围隔离、失败恢复、
跨格式与数据集旁路回归；最后才做真实检索质量评估。减少切片或通过结构校验不等于
质量提高。无维护者新的部署授权，不迁移生产数据库、不重建历史队列。

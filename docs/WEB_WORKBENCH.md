# 阅读工作台与草稿恢复

这份说明对应 CZ-U08。它改变的是藏知原生网页，不是将整个网页嵌入弹窗；
检索、问答、数据集执行和鉴权继续由原有服务负责。

## 从资料到答案

1. 在“搜资料”输入关键词或选择筛选条件。点结果标题或“阅读原文”，即可在阅读区
   核对命中段落与可用的章节上下文；不会自动调用模型生成摘要。
2. 桌面上列表与阅读区并排，阅读区可以收起；手机切换“搜索列表 / 阅读”，保留
   查询、筛选、页码和列表位置。键盘可用 Tab / Enter 打开，Escape 收起并返回触发项。
3. “仅问这份资料”进入明确限定文档的问答页面。先检查范围、输入问题，再点发送；
   点击入口本身不发问、不消耗模型调用。
4. 问答桌面分为“范围与记录 / 问答 / 引用证据”三区，侧栏和证据栏可收起。
   手机直接切换区域，不用关闭遮罩才能继续输入。引用区保持回答所引用的版本。

阅读区是有界上下文预览，不是整篇全文。PDF/Word 可选择版本绑定的文件版式，
只有原文件/预览文件使用 iframe；资料管理仍在“完整文档与管理”。数据表显示原始行
和版本，不把旧快照称为实时源库数据，也不把模型概括当作精确计算。历史版本不可读取时
明确报错，不悄悄显示新版。Markdown 不执行 HTML，也不自动加载外部图片。

## 草稿与离页提示

| 内容 | 保存位置与行为 |
|---|---|
| 新建、编辑随手记 | 当前标签页的 sessionStorage，按空间与资料编号隔离；最多 24 小时、单份 512 KiB。恢复状态可见，可主动丢弃；成功保存后清理 |
| 尚未发送的问题与筛选 | 当前标签页，按空间和指定资料范围隔离；登录后回原入口继续，不自动发送 |
| 资料标题、摘要、标签、分类 | 不自动缓存，离开前提醒；轮询不会覆盖当前编辑内容 |
| 模型/API 密钥与密码 | 不持久化到浏览器草稿；模型设置有未保存离页提醒 |
| 文件选择与上传 | 不承诺刷新后续传；待上传或正在上传时离页提示。已被服务端接收的文件可能继续处理 |

浏览器禁用存储、配额不足或内容超过上限时会明确提示，未成功暂存的输入启用离页保护。
关闭标签页、清理浏览器数据或隐私浏览会影响恢复；这些不是云端草稿，也不能代替正式保存。
公共或共用设备不要依赖浏览器草稿保存敏感正文。

编辑随手记时，如已保存原文的版本变化，会保留本地草稿并要求核对。保存前再次读取
最新版本；现有 API 尚无原子比较并更新契约，因此不能保证消除跨设备同时写入的最后瞬间竞争。

登录失效不会主动关掉编辑页。页面提供“重新登录后继续”，顶栏也会在重新聚焦及每分钟
检查登录状态，给出返回当前页面的入口。未保存的敏感配置不随登录恢复。

## 开发者验收

在 `apps/web` 中运行：

```sh
npm ci
npm run test:ux
npm run lint
npm run typecheck
npm run test:browser
npm run build
```

`test:browser` 使用 Playwright 和独立 Chromium 进程，不使用用户浏览器配置。
默认探测 `/usr/bin/google-chrome` 或 `/usr/bin/chromium`，其他位置可通过
`CANGZHI_TEST_CHROMIUM` 指定；也可使用 Playwright 自己安装的 Chromium。
测试会启动随机回环端口的合成 API 和 Next 开发服务，结束后关闭，不访问部署实例或模型。
不要与另一个使用同一 `.next/dev` 的开发服务同时运行。截图输出到系统临时目录，
只包含合成数据，不自动进入仓库。生产构建会恢复 Next 的生产路由类型文件。

浏览器验收涵盖草稿跨页/空间隔离/过期登录、键盘打开原文、限定资料问答、桌面证据并排、
390px 手机区域切换和压缩视口、未保存导航取消/接受以及前进后退。
压缩视口只是软键盘占位模拟，不等于 iOS/Android 真机输入法、屏幕阅读器或所有网关的验收。
完整 API/Worker、真实来源库、真实模型输出质量和部署仍需各自独立验证。

# 运行概览

入口：设置 → 运行概览（`/settings/overview`）。仅管理员浏览器可读，覆盖全部工作空间，
不向 PAT、探索凭证、REST v1 或 MCP 增加系统统计权限。

## 性能与采集

- 普通 Worker 内独立低频采集线程，独立连接池最多一个连接，不占用文档任务执行槽。
- 队列每60秒尝试；知识规模、容量每900秒尝试。PostgreSQL事务咨询锁与持久尝试时间
  防止多个 Worker 或反复重启重复采集。无手动强制全量采集接口。
- 队列只统计未完成/失败状态，0040增加相应部分索引，不每分钟扫描累计完成任务。
  首次建索引会读取任务表，大规模安装应安排维护窗口执行迁移。
- 聚合在SQL中完成，不取正文、JSON结构或向量数组。每条SQL最多2500ms、锁等待200ms，
  禁用该连接的并行查询；轮次超过30秒不再启动下一组。统计仍有数据库开销，不能承诺
  零影响；超大库超时后保留旧结果，后续可演进增量计数，不自动放宽资源限制。
- 磁盘容量使用挂载点统计，不递归扫描目录。Blob与Parquet按登记字节计算，不逐文件stat。
- 页面只读取三条快照、最多100条指标状态与最多721个小时点，30秒串行刷新、10秒超时，隐藏页面暂停请求。
  “重新读取快照”不触发采集。失败保留旧值，分区标记采集时间和过期；未采集显示未知。
- 每小时一个趋势点，保留31天监控派生数据，不保存原文、文件名、路径、凭证或Scope Key。
  只清理监控历史，不删除事实源。刚启用时没有历史，至少跨两个小时才有趋势曲线。

## 口径

- 有效文档：所有未回收文件、网页、随手记；上传文件是其中source_type=file的子集。
- 内容版本包含历史和回收站版本。在线父/子切片限当前文档版本、is_current、未回收。
- 全部向量含历史和候选Profile；当前有效向量匹配active Profile及在线子切片内容哈希。
  不输出简单向量/切片覆盖率，数据集抽样与应构建覆盖继续以向量设置页为准。
- 数据集计当前版本的ready目录，不代表每次DuckDB查询都已验收。
- Blob按对象去重；同时被原件和预览引用的对象只计原件。PDF预览、其他Blob互斥分组。
  Parquet按ready产物登记字节。未登记临时文件、备份、镜像、文件系统开销不在此分类内。
- 数据盘使用率包含同盘其他程序；数据库可能在另一块盘，不将数据库大小与数据盘简单相加。
  向量表占用含其索引，已经包含在数据库总大小中。
- 队列计当前未回收文档的任务行，不是文档数，失败可能包含已重试的旧尝试；最早排队时间
  含等待退避重试。WebDAV独立扫描任务仍在知识源查看。
- 多条聚合为低频观测，持续写入时不保证各计数同一事务快照；各区时间不同，不强行对账。

## 运维与局限

模型额度统计只展示真实容量池，不把`scope:`内部故障隔离状态和探测租约计算成
新增配额。后台上限显示实际生效值：总量大于1时至少预留一个前台名额。
单模型冷却不等于全池不可用；这些采样计数仍不能证明模型可正常生成答案。

需先迁移0041并更新API/Web/普通Worker；升级不重新处理历史资料或调用模型。
页面出现过期提示时先检查Worker与数据库；某组失败不会清空该组旧数据或阻塞其他组。
磁盘不可读显示暂不可用，SQLite不提供PostgreSQL容量指标。

本批全局统计，不提供工作空间筛选；未接入检索P95、成功率、模型费用、备份完成时间、
CPU/RAM或外部告警。磁盘>=90%页面提示；不伪造系统健康评分，不自动删除数据。
局部统计失败记录通用错误，不回显原始SQL异常；监控自身健康不等于整个Worker健康。

### 有效向量计数性能修正（后续补丁）

哈希一致性放在聚合的FILTER中判断，而不是作为连接选择率条件；统计含义仍是
活动Profile、当前未回收资料的在线子切片且内容哈希一致。避免数据库把实际数万条
匹配错误估成单行，进而对每条向量反复扫描文档表。保留2500ms超时和低频采集，
不修改数据库全局优化器参数，也不重建向量。隔离PostgreSQL以5万条合成向量验证
计数、失效哈希、历史版本和回收资料排除；单次现场只读观察不是P95或容量保证。

0041增加指标级隔离：单个探针失败保留该项旧值与旧时间，其余指标继续；首次失败
明确显示无可用结果，不再写成等待首次执行。失败指标按60–3600秒退避，刷新页面仍
不会触发采集。展开可见各指标成功/尝试时间及预计重试时间。无预算未执行不计作失败。
同一SQL产生的多个计数共用该次成败。小时趋势按实际成功观测所属小时更新，不把旧值
移到新小时。设计见[ADR-033](ADR-033-monitoring-metrics.md)；模型并发及任务恢复是
后续独立验收节点，见[处理可靠性计划](PROCESSING_RELIABILITY_PLAN.md)。

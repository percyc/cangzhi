# ADR-027：数据集字段语义作为可校验派生建议

## 背景

类型、空值、唯一值、范围和样例可以由程序确定，但缩写字段、隐含单位和业务别名
会降低数据集发现和自然语言问答的映射质量。只根据少量样例让模型自由解释，又容易将
推测写成事实。

## 决定

1. `DatasetField` 的程序画像是事实层，不由模型改写。
2. AI 以整个数据集上下文分批生成字段说明、单位、别名和置信度；只接受与原字段名
   精确匹配且经过长度、类型、数量校验的输出。
3. 语义生成是可重建、非阻塞的低优先级派生任务。未配置模型、模型失败或输出不完整时，
   Parquet/DuckDB 与程序画像继续服务。
4. 数据集管理页允许显式生成或重新生成；REST v1、MCP、快速问答和深度分析共享同一
   Schema 语义。查询执行仍只能引用真实字段名和白名单计划。
5. 单个超宽数据集最多自动分析 320 个字段，并标记为 `partial`，避免不受控的调用成本。

## 后果

缩写和业务问法的映射会更稳定，但 AI 说明仍可能不准确，页面和接口必须暴露来源与置信度。
后续如增加用户确认或来源数据字典，其优先级必须高于 AI 建议，且重新生成不得覆盖已确认内容。

# ADR-038：快速问答的计算上下文与有界纠错

日期：2026-10-23。实施状态见 PROJECT_STATUS。

## 判断

快速问答应当提供可靠的单次检索与精确计算，不是省略单位和口径的简化答案。
深度分析适合不确定的多步发现与交叉验证；不因快速回答证据不足就隐式升级、重复计费。

## 决策

- 保留快速问答的范围内目录发现、受校验计划、计算和带引用回答。初始计划至多
  两次格式校验尝试，零行、截断或单位冲突至多一次语义纠错，不添加无界工具循环。
- 单位/币种必须来自相同筛选条件、相同数据版本的真实行。只识别明确的通用列名
  （单位、计量单位、unit/uom、币种/currency等）；不把AI字段建议、抽样值或问题中
  的措辞当作事实单位，不进行自动换算。未识别和全空时明确未知。
- 数值聚合对命中范围核验这些上下文列；单一非空值才可作为整项单位。多单位或
  部分缺失时，若未按该上下文分组，不把混合数值提供为可用合计；允许有界纠错
  在保持原筛选、指标及范围不变的前提下按单位分组，不能任意筛掉冲突行。
  计数不继承被计数对象的货币/物理单位。
- 核验在已有DuckDB连接、同一Parquet及查询超时内完成；兼容行执行器复用同一
  筛选语义。只输出少量单位值及计数，不向模型发送完整贡献行。不是第二次模型推断。
- 快速问答证据包含执行条件、计算上下文、缺失/混合/截断状态。仍不安全时明确
  证据不足并建议明确口径或选择深度分析，不让模型凭常识补全。

## 接口与非目标

HTTP层不复制规则。网页快速问答、REST quick和MCP knowledge_ask统一调用服务。
不更改公共查询请求格式、不新增权限、隐式空间或范围，也不改变公共数据集工具的
原始查询语义；本批核验通过内部执行选项启用，结果保留在问答证据/聚合元数据。
不保证所有单位列名自动识别，不做量纲换算、跨表连接、复杂比率和通用语义加总证明。
跨层级、跨期、非可加总指标仍需模型规划与独立质量评估，不能据单个案例判定正确率。

## 验收

同单位、混合币种、空/部分缺失、按单位分组、无单位列、计数、非数值/零行、
引号列名、跨范围、截断和大表下推必须测试；明细/文档问答不可退步。
私有实例数据与部署记录仅保留本地；公共测试使用合成数据。

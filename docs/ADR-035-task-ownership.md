# ADR-035：任务所有权与可终止执行（开发草案，禁止启用）

日期：2026-10-23。分支`codex/CZ-Q09-admission-recovery-draft`，负责人Codex。
状态：实现未通过完整验收，不合入main、不部署；生产仍是0041。

## 目标

不破坏原文件、document_versions和既有可用索引，给普通Worker、维护和重切执行器
统一任务所有权。使用worker_id、attempt_id、有限租约、心跳和硬截止时间；
领取量不得超过实际执行能力，同文档不能被不同阶段同时修改。
模型额度由ADR034负责，CPU/解析执行容量不是同一个计数器。

长任务拟采用可终止的复用子进程、独立响应管道和有界帧协议，日志不能污染协议。
超时或失联应先确认执行退出，再考虑延后/失败；无法确认退出必须隔离，不能仅延长
过期租约后假定安全。旧无租约processing任务不能自动接管。

## 当前实现不是安全证明

0043草案、lease/task_execution模块、领取分支和基本测试已形成原型，默认
task_execution_enabled=false。模型新增字段意味着即便关闭开关，草案代码也依赖
0043，不能拿它直接替换0041生产镜像。不能仅凭开关关闭就合入正式版。

父级审阅发现以下阻断项，必须通过真实PostgreSQL及子进程集成测试逐项关闭：

- 心跳等待条件、短连接/锁等待有界、终止后回收使用严格CAS。
- 同一批和多个领取者均须满足同文档互斥；不能只用NOT EXISTS先读后改。
- 发布检查不能用populate_existing覆盖ORM待提交数据，也不能递归自动flush；
  验证旧尝试和终态提交时不能持有任务锁跨越模型等待。
- 强制终止、父进程退出、部分响应帧、子进程日志、无法确认退出均须实测。
- 恢复次数有限；付费增强结果未知不能自动重放，隔离态不能再次被过期领取。
- 版本、哈希、配置/Profile和删除状态变化应拒绝旧结果；派生文件按尝试隔离，
  迟到清理不能删除继任者的Parquet/PDF或在线索引。
- 补齐真实管线成功/失败提交、重启、迟到写入和大量小向量任务开销验证。
  SQLite基本所有权和纯协议测试不等价于这些发布验收。

## 交付约束

这是开发分支交接记录，不是部署说明。不得启用开关、自动恢复历史任务或增加并发
绕过上述问题。下一位协作者先读本文件与处理可靠性计划，修复测试夹具和真实协议，
再决定保留或简化原型。未经上述验收不得发布v1.4.0。

# ADR-035：任务所有权与可终止执行

日期：2026-10-23。实施分支：`codex/CZ-Q09-reliability-complete`。
本 ADR 取代原型交接警告；实际验收、部署和提交见 PROJECT_STATUS / DEVLOG。

## 目标与执行

不改变原文件、文档版本和检索契约。普通 Worker、维护和重切执行器共享任务所有权，
新增 worker_id、attempt_id、lease_until、heartbeat_at、hard_deadline、attempt_count、
recovery_count、quarantined_at。迁移 0043 后默认启用，要求 PostgreSQL；测试显式关闭。

CPU 仍串行，每次只领取实际能执行的一个任务。不同领取者使用同一文档 advisory lock，
执行子进程持有文档会话锁直到任务结束，过期租约本身不能证明旧执行已退出。
已知忙碌文档先从候选中排除，再在锁内核对，避免其大量待办阻塞其他文档。

任务在复用的 exec 子进程运行，不 fork 已有数据库连接和多线程状态。独立响应 FD、
有限长度帧及读取期限隔离日志污染/部分帧。父进程心跳与硬截止监督任务；停止时终止
整个执行进程组并确认退出，包含继承进程组的本地转换/OCR 子进程。父进程消失时子进程
监测并退出。不能确认退出则持久隔离，不再领取，交维护者检查。

## 提交保护和恢复

- 首次派生写入按文档→任务锁顺序检查尝试、配置、当前版本、哈希、删除状态及向量
  Profile 指纹；读取使用 Core SQL，不覆盖待提交 ORM 对象、不触发递归 autoflush。
- 发布事务持有文档/任务锁；提交再次验证所有权和硬截止。此时心跳锁等待不能误杀合法
  发布事务：软租约可在持锁期间经过，发布在硬截止前续租并释放锁。模型等待不能故意
  包在发布事务中；数据库连接/语句/锁等待有界，任务总期限限制剩余执行。
- 支持原管线终态提交后的后续事务、网页正文首次哈希和快照自身版本推进。外部版本/
  哈希变化拒绝旧结果；Parquet 每次构建使用 UUID 唯一路径，数据库引用决定当前产物，
  旧尝试清理不能删除同版本的新文件。不宣称所有既有重切流程已改为整代索引原子切换。
- 停止后的恢复必须 CAS 匹配原 attempt 且仍 processing，不能覆盖成功或继任结果。
  默认累计 3 次中断后终止（recovery_count 与普通 retry_count、领取次数分开）；
  退避后重领才得到新 attempt。增强计费结果未知不自动重放。
- 无租约的旧 processing 任务不自动接管，历史 failed 不重置。隔离只能在确认旧进程
  退出后由维护者显式处理，不能仅清空标记让两个执行器同时工作。

## 默认预算

租约 120 秒、心跳 30 秒；stored/parsing 7200 秒、embedding 180 秒、chunking 3600 秒、
preview 600 秒、其他阶段 3600 秒硬截止；终止宽限 15 秒。参数有安全夹取，心跳小于
租约。升级仍应等待当前任务自然结束，不能把 Compose 有限停止宽限误当作必然成功。
`TASK_EXECUTION_ENABLED=false` 仅用于明确兼容/排障，不作为无迁移运行新镜像的方式。

## 验证与观测

测试分为 SQLite 业务回归、真实 PostgreSQL 所有权/迟到写入、真实子进程管线/故障，
以及 2000 个无模型小任务的完整监督开销测量。测试数据均为合成，不能当作外部模型
吞吐或复杂文档质量承诺。发布必须实际运行条件测试，不以默认跳过视为通过。

处理中心区分模型额度等待、执行中断退避和隔离；运行概览增加模型池采样占用、等待量、
隔离量和累计恢复次数。监控采样线程心跳不冒充任务心跳。新增表/字段为可回退迁移，
但运行中不得降级：先停止执行器、保留备份和旧镜像，再按部署手册切换。

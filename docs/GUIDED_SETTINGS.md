# 配置引导与设置搜索

在“设置 → 配置引导”按用途完成配置。所有模型设置全局共享，不随工作空间切换。
已有连接不会因为打开向导、切换步骤或跳过可选步骤而被修改。

## 推荐顺序

1. **对话与整理**：选择 OpenAI 兼容服务或本地 Ollama。填写地址、密钥后，可以获取
   模型列表，也可以直接输入模型名。保存与连接测试分开执行；保存可用对话配置会沿用
   既有行为，为历史未分类资料补充整理任务。测试会发送小型测试请求，可能计费。
2. **语义检索（可选）**：可以复制已保存对话连接的地址和密钥，另选 Embedding 模型，
   也可以填写独立连接。这里只保存向量设置，不保存其他面板草稿、不触发对话补跑。
   保存后测试兼容性，再明确构建和启用索引；不会自动全库向量化。
3. **外部图片文字识别（可选）**：本地 OCR 无需配置外部服务。需要额外识别时选择
   支持图片的视觉模型，确认候选页面外发和页数上限后保存、测试。
4. **检查与开始使用**：核对已保存配置、当前会话的测试结果及索引状态，前往上传资料、
   知识源或问答。未经本次测试的已有连接不冒充测试成功；跳过不等于关闭已有能力。

复制连接是**一次性复制，不是持续关联**。以后修改对话地址或密钥，不会自动更新
向量和 OCR。密钥不回显，也不会保存到浏览器草稿；重新打开页面只显示是否已保存。
使用已保存密钥获取模型列表时，地址必须与保存时一致；新地址需要明确输入密钥。

模型列表只列名称，不能保证它支持向量或图片；列表获取失败也可以手动填写并测试。
向量配置与当前索引不匹配时，现有检索会降级关键词；旧向量数据仍保留，不意味着
新模型已经用于检索。请在详细“向量与索引”页面检查和完成索引生命周期。

## 找不到设置时

每个设置页都有“搜索设置与功能”。输入名称或常用问法，例如“怎么修改密码”、
“上传太大”、“连接数据库”、“MCP”、“磁盘占用”，跳转到对应真实操作入口。
搜索在本地功能目录中执行，不查询知识库内容，不传配置值或密钥，也不调用模型。
没有匹配时可缩短关键词或查看设置分类。
手机端先展开“查找或切换设置”；收起不会清空当前搜索词。

## 切换设置页面

设置区使用共享导航布局。切换分类只更新右侧内容，左侧搜索词、菜单滚动位置、
手机工具区展开状态和已打开的版本信息会保留；点击当前分类不会重复跳转。
页面首次读取配置仍需等待接口，加载或失败提示只显示在内容区，不会移除导航。
保留范围仅限当前设置区会话；刷新网页或离开设置区后重新进入，不保证恢复这些状态。

这不是配置缓存：重新进入表单仍读取服务器保存值，不自动保存或长期保留密钥草稿。
对话、向量和OCR在同一模型页内切换继续保留当前草稿；跨页离开仍使用未保存确认，
浏览器前进/后退沿用全局离页保护。版本核对结果可手动点击“重新核对”更新。

本批不包含 AI 自动配置聊天：向导和搜索在没有模型时也必须可用。后续如果增加 AI
解释，只能提供可核验的建议，不应直接处理密钥或代替用户保存、构建、删除配置。

## 开发验证

- API：`pytest apps/api/tests/test_settings_ai.py apps/api/tests/test_settings_connections.py`，
  使用隔离测试库和密钥，不连接实际模型。
- Web：在`apps/web`执行`npm run test:ux`、`npm run lint`和`npm run typecheck`。
- 浏览器：`npm run test:browser:settings`会启动仅本机可访问的合成API和Next开发进程，
  验证跳过、独立保存、复制、草稿、搜索、键盘、跨页导航实例/滚动保留、读取失败
  和390/1024/1440布局。需要可用的
  Playwright Chromium；不要与另一个使用同一`.next`目录的开发进程同时运行。

上述合成测试不替代供应商真实兼容性测试；是否发送真实请求由管理员在页面明确发起。
